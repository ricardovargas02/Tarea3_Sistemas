Integrantes: Daniel Carmona y Ricardo Vargas
Asignatura: Sistemas Operativos
Descripción
Este proyecto consiste en desarrollar un simulador de asignación de archivos en disco, utilizando C++17.

Estado del proyecto:
El proyecto se encuentra en desarrollo. Se irán incorporando los mecanismos de asignación y las funcionalidades solicitadas en la guía de la tarea.
Las instrucciones de ejecución y los detalles de implementación se agregarán a medida que avancemos.
